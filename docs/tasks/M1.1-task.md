## 0. 用户原话与现象
用户原话：「你这ui做的什么乱七八糟的」＋「弹窗布局还是要之前 wails 的那个布局，不要修改。」
截图证据：`/var/folders/p7/_l176myj70xfc6klwt56qwfr0000gn/T/otty-paste/image-1791539571084.png`
现象（截图里能看到的）：
- 详情、搜索结果列表、下载条 **三层同时可见并互相透出**：列表书名/右侧 ID 透在详情上，详情的简介/目录文字压在封面与列表行上，全部读不清；
- 详情的大标题画在窗口最顶部，**压住顶栏的搜索框**；

## 1. 根因（代码位置，先看再改）
- `Sources/Features/Root/RootView.swift:11-56`：`overlayLayer` 只是把 `BookDetailView` 摞在 ZStack 上层，**没有遮罩（scrim）**，底层列表原样透出。
- `Sources/Features/Detail/BookDetailView.swift:22-24`：详情卡片 `frame(width: 900)` / `maxHeight 660` + 玻璃材质，并且 `RootView.swift:46` 用 `fmGlassTransition(.matchedGeometry)` 从列表卡片形变展开 → 源卡片与目标详情同时可见。
- 结论：现在的弹窗是**自创的"整窗玻璃形变浮层"**，旧版 Wails 根本没有这种东西。旧版是"居中模态弹窗 + 半透明黑遮罩 + 实色圆角面板"。
