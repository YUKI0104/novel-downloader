## 2. 要做成什么样
1. **主页默认显示榜单**（与旧版一致）：进 App 就是榜单页；顶栏 + 频道行 + 封面网格结果。
2. 频道行照旧版：`综合热榜`（默认，active）/`男频`/`女频` 三个频道按钮；**「改编书单」按钮这一轮不放**（旧版默认 hidden，属 M3 短剧线）。
   - 频道=综合热榜：隐藏榜单类型/题材两个下拉，直接取 `https://fanqienovel.com/rank`。
   - 频道=男频/女频：显示 `rank-type`（阅读榜 1 / 新书榜 2）与 `rank-genre`（题材，随频道变化），切任一项都重取。
3. 结果用**封面网格**呈现（复用 AlbumCard，序号用封面左上角角标）；序号 1–10，**前三名角标用橙色**（旧版 `.rank-no.top`）。
4. 搜索后切到结果视图，结果区顶部有「**返回榜单**」按钮（照旧版 `.search-head` 位置：状态文字在左、返回按钮在右），点了回到榜单页。
5. 加载中/失败：照旧版在榜单状态位显示文案（失败显示「加载榜单失败: <原因>」），不要弹窗。
6. 榜单数据完全照搬旧 Go 逻辑（同一 URL 结构、同正则、并发 8、保持顺序、60s 缓存），**不许自创接口**。

## 3. 禁止
- 禁止改动：搜索/详情/下载/弹窗/对齐/网格数值/窗口玻璃/内核与下载逻辑/文案与配色。
- 禁止自创榜单 UI（按钮文案、下拉项、序号样式照旧版）。
- 禁止把榜单做成"搜索的一种"（旧版是独立默认视图 + 搜索后切换）。
