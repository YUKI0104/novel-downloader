# M13：榜单页加「刷新榜单」按钮

> 用户 2026-10-12 批注（截图：分段行右侧、☰ 图标左侧的红框空位）：「加一个刷新按钮」「这个刷新按钮就是榜单刷新用的」。

## 要求
1. **位置**：榜单页（综合热榜/男频/女频 那一行）**右侧、☰（视图切换）图标左边**的空位——即用户红框处。搜索页不加。
2. **样式**：与顶栏既有图标按钮**同一款**（同尺寸/同圆角/同 hover），图标用刷新类 SF Symbol（`arrow.clockwise`；先探活，不可用再回退 `arrow.triangle.2.circlepath`）。
3. **行为**：点击 = **重新拉取当前榜单**（保持当前频道：综合/男频/女频；保持 TOP10 口径），完成后刷新卡片（含短剧角标，短剧开关开着时照旧按 ID 重查）。
4. **加载态**：请求中图标转起来或按钮禁用（二选一，别让用户连点造成并发请求）；沿用既有 NetworkRetry（3 次退避 1/2/4s）。
5. **自解释**：`.help("刷新榜单")`（图标按钮必须自解释）。
6. 不改变布局：窗口 1000×820、卡片 176.8×295、封面 195、左右留白 30/30、右侧图标群右边界（970）不变；刷新按钮插进现有间距里，不挤压、不换行。
