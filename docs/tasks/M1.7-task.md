## 1. 要做的六件事（逐条量，验收按这个）
1. **顶栏与频道行之间的空白去掉**：频道行（综合热榜/男频/女频）往上挪进那条空白，频道行与顶栏的间距 = 现有元素间最小间距（10–14pt），不许再留一条空带。
2. **左侧/右侧空白收掉**：把内容区左右 inset 从现在的基准线收到窗口内容边（约 18pt），**但"顶栏最左元素左边缘 == 结果区最左元素左边缘、顶栏最右元素右边缘 == 结果区最右元素右边缘"这条红线不能破**（两边一起收，仍然对齐）。
3. **滚动条不得遮挡卡片内容**：在最右侧留一条只给滚动条的窄槽（约 12pt，颜色 = 页面底色），让覆盖式滚动条浮在槽里，而不是压在最后一列卡片上；滚动条静止时不显示。
4. **卡片尺寸全部一致**：同一行/所有行卡片的宽高必须**完全一致**（frame 数字 10 张全等）。
   - 封面：固定高度（照旧版 210pt）× 列宽，图片 `.fill` 裁切（不许出现因图片宽高比不同而高度变化、也不许留白边）；
   - 标题区：**固定两行高度**（单行标题也占两行高度，超出两行省略），meta 一行 → 卡片总高恒定。
   - 先 dump 改前 10 张卡片与封面的 frame 数字，改后再 dump 一次给我对比。
5. **加载/空状态不要色差**：内容容器不要再有自己的底色（或底色必须与页面底色一致）。加载时显示「加载榜单...」+ 可选灰色骨架卡（骨架卡的底色也要与卡片一致，不要第三层色）。绝不允许出现"比页面更深/更浅的大方块"。
6. **失败态加「重试」按钮**（Q2=甲）：在失败文案右侧放一个 ghost 小按钮「重试」（风格照旧版 `.btn.ghost.small`），点击重取当前榜单；文案仍是一行中文（M1.6 已修的口径不变）。
