## B 下载按钮做成状态机（用户原话）
> 「点击下载，下载按钮填充绿色从左到右，下载完按钮变成绿色（常挂除非删文件）然后绿色按钮的下载变成打开访问按钮」

1. **未下载**：蓝色按钮「下载」（现状）。
2. **下载中**：按钮内部**从左到右填充绿色**实时反映进度（原来那条独立进度条可以并入/移除，不要两个进度并存）。
3. **下载完成**：按钮**整体变绿并常挂**，文字由「下载」变成**「打开」**；点击 = **打开已下载的文件**（默认应用打开那个 .txt）。
4. **常挂条件**：只要**文件还存在**就保持绿色「打开」态；文件被删（外部删除/移动）→ 回到蓝色「下载」态（每次进入详情/刷新时核对文件是否存在）。
5. **用户拍板（甲）**：绿色「打开」按钮**右边保留放大镜图标按钮**（在 Finder 中显示，`.help` 提示不变），**删掉「✓ 下载完成」那行文字**。
6. 失败态（下载出错）保持现有文案/行为，不要因为改按钮而丢错误提示。
