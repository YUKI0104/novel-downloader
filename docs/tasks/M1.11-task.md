# M1.11 任务书 — 详情弹窗改成固定尺寸（高度放大、简介可留白）

用户原话：「Q1，宽度是OK的，就是高度太小了，稍微放大一点。但我需要固定弹窗尺寸，简介空一些也没关系。」
（前一问 Q1 我给的三个选项是：甲 固定尺寸且内容撑满 / 乙 固定尺寸且内容靠上、下方留白 / 丙 不固定。用户答＝**要固定尺寸**，宽度保持现在这样**（≈950pt，不要跟着红框缩到 913）**，高度要**比现在（约 380pt）明显大一点**，简介区留白可以接受。）

## 1. 要做成什么样（逐条量）
1. **详情弹窗固定尺寸：宽 950pt × 高 600pt**（在 1000×800 窗口的现有留白下居中摆放）。**换书、简介长短不同，弹窗尺寸必须一模一样**（不再随内容变高）。
   - 数字定这个先做；用户如果要微调高度，一句话就能改（做成一个常量，别散落各处）。
2. **内部布局**（右列顺序保持 M1.9 定稿的）：
   - 顶部：标题行 + 平台 chip（一行）
   - 内容区左右两栏：左＝封面（**高 = 内容区高**，宽 = 高×0.75，仍与右列同高、底边对齐）；右＝信息列
   - 右列：`ID 行（含复制/复制链接）` → `作者行（作者+题材）` → `统计 chip 行` → **简介块（占据中间剩余空间，文字少就空着，可滚动）** → `下载按钮 + 章节提示行（贴内容区底部）`
3. **简介块不再是固定 320 封顶**：它撑满"统计 chip 行"到"下载按钮行"之间剩余的空间；简介短的书的就在这块里留白（用户明确说可以）。
4. 封面与右列底边对齐这条红线保持；封面比现在大一些是预期结果（内容区高了，封面跟着高）。

## 2. 禁止
- 禁止动：下载管理弹窗与删除确认弹窗的尺寸规则、主页（顶栏/网格/列表/左右 30pt 基准）、窗口固定 1000×800、卡片尺寸、榜单与抓取逻辑、文案口径。
- 禁止把弹窗做成"跟着内容变高"或"跟窗口等比缩放"。

## 3. 交付与验收（交给我）
1. 两本**简介字数明显不同**的书各一张详情截图：两张的弹窗**尺寸数字完全相同**（贴 frame：950 × 600）。
2. 简介短的那本：底部有空白但不出现拉伸变形/文字溢出。
3. 封面高 == 右列高（贴数字）。
4. 弹窗在 1000×800 窗口里居中（贴四周留白数字）。
5. 说明我把高度做成了哪个常量（便于一句话微调）。
