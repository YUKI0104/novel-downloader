# M1.2 任务书 — 详情弹窗：按内容定尺寸、删留白、封面与内容同高

## 0. 用户原话与标注
用户原话：「排版按照图片里的最外面的框为大小限制，其他的留白删除，然后封面跟所有内容的总高度要一致」
标注截图：`/var/folders/p7/_l176myj70xfc6klwt56qwfr0000gn/T/otty-paste/image-1791541444778.png`
图上标注：一个红框圈住 **封面 + 右列信息（ID 行 / 统计 chip 行 / 简介块 / 下载按钮行）**，红框上沿切在 ID 行（标题行、作者行在框外上方），红框下沿 = 封面底边 = 下载按钮行的下沿；右上角另一个小框标了「关闭按钮」（指面板右上那个 ✕，位置保持不动）。

## 1. 要做成什么样（这就是验收口径，逐条量）
1. **面板高度 = 内容自然高度**：`标题行 + 作者行 + 内容区高度 + 面板内上下 padding`。删掉旧版「min-height 480 / 撑满窗口」造成的空白——面板内**不允许**出现内容之外的空区（尤其是内容下方那一大块）。
2. **内容区高度 = 封面高度 = 右列信息总量高度**：封面底边与右列（ID 行→统计 chip→简介块→下载按钮行）的底边**严格对齐**，就是那条红框的下沿。
3. **封面尺寸**：保持 3:4（宽 = 高 × 0.75），宽度落在 230–380 之间；如果按内容高算出的宽度超出这个区间：取区间边界值算高度，但**仍以"封面底边与信息列底边对齐"为第一优先**。
4. **标题行 + 作者行**保持在红框上方（现状），**关闭按钮**保持面板右上、与标题行同一视觉高度，不动。
5. 面板宽度保持 `min(960, 窗宽-40)`，窗口内居中；遮罩行为不变。
6. **下载管理弹窗**同理去掉多余留白：面板高度按内容（标题 + 按钮行 + 列表自然高度）；列表为空时给一个合理的最小高度，别塌成一条。

## 2. 实现提示（不强制，能达标即可）
- 不要在 HStack 里靠 `align-self: stretch` / `frame(maxHeight: .infinity)` 拉伸封面。
- 建议：用 `GeometryReader` + `PreferenceKey`（或 `onGeometryChange`）量出右列信息列的真实高度 H，再用 `frame(width: H*0.75, height: H)` 定封面；两列放进 `HStack(alignment: .top)`。
- 面板容器（`FMModalPanel`）要支持"高度由内容决定"的模式：不要固定 `minHeight`，让内容撑高。

## 3. 禁止
- 禁止改动：弹窗结构（标题行/作者行/ID 行/统计 chip/简介块/下载按钮行的顺序与文案）、配色、遮罩行为与关闭路径（✕ / Esc / 点遮罩）、窗口最外层背景玻璃、顶栏、搜索/列表区、内核与下载逻辑。
- 禁止自创新布局；只调尺寸与留白。

## 4. 交付与验收（交给我）
1. 详情弹窗截图（按窗口截，不截全屏），必须能看到：面板下沿紧贴内容底边、封面底边与信息列底边对齐、面板内无空块。
2. 换一本**简介字数不同**的书再截一张，确认高度随内容变化（不是写死的）。
3. 下载管理弹窗截图 1 张（去掉留白后）。
4. 回我三个数字证明关系：**封面高度 H、信息列高度 H'、面板总高度**，并说明面板 = 标题行 + 作者行 + H + padding 的算式。
