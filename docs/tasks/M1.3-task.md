标注截图：`/var/folders/p7/_l176myj70xfc6klwt56qwfr0000gn/T/otty-paste/image-1791541621279.png`
图上标注（我按像素量过，窗口 1180×800pt、截图为 2x）：
- 红框 = 顶栏那一条：**红框左边缘正好压在顶栏最左元素「番茄小说」胶囊的左边缘上**（≈99pt），上边缘在顶栏上方（≈55pt）；
- 结果卡片/列表的左边缘在 ≈44pt，**比顶栏往左凸出约 55pt**，所以看起来"没对齐到框里"。

## 1. 要做三件事

### (1) 主页面内容对齐到同一个框
- **结果区（列表或网格）的最左元素左边缘 ＝ 顶栏最左元素（「番茄小说」胶囊外框）的左边缘；最右元素右边缘 ＝ 顶栏最右元素（设置齿轮）的右边缘。** 误差 ≤1pt，用像素测量证明（截图里量，或用 swift 脚本量 frame）。
- 滚动条不要因此把内容挤偏（内容区宽度固定，滚动条覆盖不参与布局）。

### (2) 结果以封面形式呈现（照旧版"相册模式"照搬）
参照 `~/code/novel-downloader/frontend/src/style.css` 786–830 行（`.results.album` 系列），数值照抄：
- 网格：`display:grid; grid-template-columns: repeat(auto-fill, minmax(150px, 1fr)); gap:14px` → SwiftUI `LazyVGrid(columns: [GridItem(.adaptive(minimum: 150), spacing: 14)], spacing: 14)`。
- 卡片：竖向排列、`padding:0`、`overflow:hidden`、圆角 `--radius`(12)、1px 边框 `rgba(60,60,67,.14)`、卡片阴影 `--shadow-sm`，hover 抬 1px + `--shadow-md`。
- 封面：占卡片整宽 × 高 210pt，**圆角 0**（由卡片裁切），`object-fit: cover`。
- 封面下方信息区 padding `10px 12px 12px`：标题 13.5px、**最多两行**（超出省略），meta 一行 12px（作者/评分/字数）。
- 相册模式**隐藏**简介摘要与右侧箭头；榜单模式（`rank-no` 序号）改为**封面左上角角标**：黑 55% 底 + 白字 13px + 圆角 8 + padding 2/9。
- 搜索空结果 / 加载中状态保持现状。

### (3) 封面/列表切换按钮（照旧版 `#btn-view-toggle`）
参照 `frontend/index.html:65` + `src/main.js:104-121`：
- 位置：**搜索框右侧**（与旧版同位置），ghost 按钮，图标在 grid / list 之间切换。
- 语义照旧版：当前是封面模式时显示"列表"图标（点它切到列表），tooltip 分别是「切换为列表模式」/「切换为相册模式」。
- 点击即切换，并**记住选择**（旧版存 localStorage `novelViewMode`；新版写进设置存储，如 `UserDefaults`/SettingsStore）。
- **首次默认 = 封面模式**（用户要求"以封面的形式呈现"）；用户手动切过后按记住的来。
- 三种结果区统一生效（搜索结果、榜单、改编书单[M3 预留]）——照旧版 `applyViewMode()` 对 `results / rank-list / af-list` 一起切。
- 列表模式保持现在的样式，不要改。

## 2. 禁止
- 禁止改动：顶栏元素本身（除了让结果区对齐到它）、弹窗（详情/下载管理/确认）、遮罩与关闭路径、窗口最外层背景玻璃、内核与下载逻辑、文案。
- 禁止自创网格尺寸/间距；照上面旧版数值。
- 禁止把对齐做成"两边各加 padding 凑数"——要以顶栏最左/最右元素为基准线。
