## 1. 详情弹窗平台 chip 写死了「番茄小说」
`Sources/Features/Detail/BookDetailView.swift:88`：`FMChip(text: "番茄小说")` → 打开七猫书（例：ID 219542 全球灾变之末日游戏，来源七猫）时 chip 还是「番茄小说」。
改：chip 跟着书来源走 → `info.platform.displayName`（番茄→「番茄小说」、七猫→「七猫小说」）。截图里 m2b-03 就是这个问题。

## 2. 改编书单筛选行：下拉没有名称，且有两个是空白
`Sources/Features/Adapt/AdaptView.swift:23-37`：`Picker("", …).labelsHidden()`，所以六个下拉只显示当前值；而「改编方向」「所属频道」当前值是空串、选项里没有 tag="" → **整个下拉是空白**（截图 m2b-07 头两个框空着，看不出是什么）。
改：
- 每个下拉显示 **「名称 ▾」**，名称＝改编方向 / 所属频道 / 作品分类 / 作品字数 / 是否完结 / 热门书单（口径：他扫一眼就知道每组是什么，不接受「看不懂的框」）；
- 空值一律显示「全部」（把 `全部` 作为 tag="" 的选项放进每组选项里，别让选择值匹配不到）；
- 六个下拉宽度按最长「名称+值」定，一行排得下、不挤；
- 分页那行（共 N 本 · 第 N 页 / 上一页 / 下一页）保持现在的位置。

## 3. 七猫榜单频道行：标签与内容对不上
现在七猫侧沿用番茄的「综合热榜 / 男频 / 女频」，而映射是 `isGirl = (rankChannel == "女频") ? 1 : 0` → **综合热榜 和 男频 点出来是同一种（男生），状态行却写「男生·大热」**。
改：
- 七猫侧频道行只留 **男生榜 / 女生榜** 两个 chip（去掉「综合热榜」），选中态就是当前 is_girl；
- 后面接榜类下拉（大热/新书/完结/收藏/更新）+「改编书单」+ 最右端切换按钮（位置不动作）；
- 状态行七猫侧写成 **「TOP 20 · 男生 · 大热 · 七猫」**（番茄侧文案一律不动）；
- 番茄侧频道行（综合热榜/男频/女频 + 题材下拉）保持原样。

## 4. 设置页「保存格式」在番茄平台下会骗人
`SettingsView.formatRow` 现在 TXT/EPUB 两档都显示，但番茄侧仍由内核决定（只出 TXT）。
改（先按「番茄固定 TXT」实现，不扩功能）：
- 番茄平台下这一行显示 **「保存格式：TXT（番茄侧固定）」**，EPUB 不可选（灰掉或直接不显示这一档），别让用户选了不生效；
- 七猫平台下 TXT / EPUB 可选，下载按这个值走七猫写出（TXT/EPUB 都已验过）。
- 文案一律中文，不用提示文字补救，直接把不成立的选项拿掉。

## 5. 卡片 meta 被省略号截掉关键信息
七猫书的作者名很长（含译者），例：`[意]乔瓦尼·薄伽丘 著;陈世丹 译 9.6 分 1万字` → meta 第 2 行被截成 `9.6 分…`，**评分/字数丢了**（截图 m2b-02 第 4 张卡）。
改：meta 固定两行的分配改成——
- 第 1 行：作者（超长用省略号，允许截断作者）；
- 第 2 行：**「评分 · 字数」完整可见**（永远不截断）。
番茄侧用同一套规则（两边卡片仍全等、仍是一屏两行、行数不变）。
