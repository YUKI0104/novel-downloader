1. **完成态按钮**：绿色底不变，**里面不再放文字「打开」，改成一个文件夹图标**（SF Symbol `folder`；先用 `NSImage(systemSymbolName:)` 探活，不可用再回退 `folder.fill`／`square.grid.2x2` 之类，务必不要空白图标）。

3. **删掉绿色按钮右边那个放大镜图标按钮**（用户选删，功能已并入主按钮）。
4. **保留悬停提示**：完成态按钮 `.help("打开访达")`（图标按钮必须自解释）。
5. 其余不变：未下载 = 蓝「下载」；下载中 = 按钮内从左到右绿色填充；绿色态常挂（文件被删/移动 → 回到蓝色「下载」）；失败态 = 蓝「下载」+ 红字胶囊提示。
