# 番茄猫 2.5.0（macOS 14+，Universal 2）

重大架构升级：彻底告别过去的 **Wails（Go + Web 前端）** 技术栈（旧 Wails 版最终版本为 **v1.3.6**），使用 **Xcode + 原生 SwiftUI（Swift 6）完全重写**。
带来纯粹的 macOS 原生质感、毫秒级响应、超低内存占用，并直接跳跃至全新的 **`2.5.0`** 版本。

## 下载

- 安装包（推荐）：`FanQieMao-2.5.0-universal-macOS14.dmg`
- 备用（压缩包）：`FanQieMao-2.5.0-universal-macOS14.zip`

## 系统要求（**重要**）

| 项目 | 要求 |
|---|---|
| 芯片 | **Apple Silicon 与 Intel 都支持**——安装包是 Universal 2 通用二进制，同一份包两代机器都能装 |
| 最低系统 | **macOS 14.0（Sonoma）或更新** |
| Intel 机器 | **必须 macOS 14 或更新**；**macOS 13、12、11 及更早的 Intel 机器打不开**（会提示需要 macOS 14） |
| 磁盘 | 约 100 MB |

只要你手上的 Mac 能升到 macOS 14，Intel / M 系列都能用。

## 功能

- **搜书**：番茄小说 / 七猫小说；书名、纯数字 ID、链接直达
- **榜单**：番茄综合热榜 / 男频 / 女频，带**一键刷新**
- **详情**：封面 / 作者 / 评分 / 字数 / 在读 / 章节数 / 简介 / 标签；ID 与链接一键复制
- **下载**：整本导出 **TXT**；下载按钮即状态机——下载中按钮内填充进度，完成后按钮变成**访达按钮**（点击在访达里定位文件），删掉文件自动回到「下载」
- **短剧 IP 命中**（默认关闭）：按小说 ID 精确匹配短剧后台，卡片角标 `上架N部·申请N次`，详情页显示后台的「已完结/上架月份 · 读者占比 · 申请/已上架/改编中 · 标签」
- **最近查看**：搜索与看过的书留档

## 安装（首次打开需放行一次）

未做 Apple 公证（本机自签名），首次打开会被 Gatekeeper 拦：

1. 打开 .dmg，把「番茄猫」拖进「应用程序」；
2. **右键「番茄猫」→ 打开 → 再点「打开」**；
3. 仍被拦时终端执行一次：`xattr -dr com.apple.quarantine /Applications/番茄猫.app`
